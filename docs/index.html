Custom Modify Headers — Privacy Policy

Last updated: 2026-09-13

Summary

Custom Modify Headers does not collect, store, or transmit any user data to the developer or any third party. All data stays on your device.

What the extension does

The extension modifies HTTP request and response headers for websites you specify, using rules you create yourself. This is done entirely on your device using Chrome's declarativeNetRequest API.

Data collection

The extension does not collect analytics, does not use telemetry, and does not send any information to remote servers. There are no ad networks, trackers, or third-party SDKs included.

Data storage

Your header rules (names, values, URL patterns, notes) are saved only in your browser's local storage (chrome.storage.local) on your own device. This data is never synced to a Google account or uploaded anywhere, and is never accessible to the developer.

Permissions

  • declarativeNetRequest — required to modify headers according to your rules.
  • storage — required to save your rules locally on your device.
  • host permissions (all sites) — required so you can apply your rules to any site you choose; the extension does not read, log, or transmit page content or browsing history.

Contact

Questions about this policy can be raised via the project's GitHub repository: github.com/Alb3it/modify-header

Custom Modify Headers — 개인정보 처리방침

최종 수정일: 2026-09-13

요약

Custom Modify Headers는 사용자 데이터를 수집, 저장(외부), 전송하지 않습니다. 모든 데이터는 사용자의 기기에만 남습니다.

확장 프로그램이 하는 일

사용자가 직접 만든 규칙에 따라 지정한 웹사이트의 HTTP 요청/응답 헤더를 수정합니다. 이 작업은 Chrome의 declarativeNetRequest API를 통해 전적으로 사용자 기기 내에서 이루어집니다.

데이터 수집

분석(analytics), 텔레메트리를 사용하지 않으며, 어떠한 정보도 외부 서버로 전송하지 않습니다. 광고 네트워크, 트래커, 제3자 SDK가 포함되어 있지 않습니다.

데이터 저장

사용자가 만든 헤더 규칙(이름, 값, URL 패턴, 메모)은 사용자의 브라우저 로컬 저장소(chrome.storage.local)에만 저장됩니다. 이 데이터는 구글 계정과 동기화되지 않으며, 어디로도 업로드되지 않고, 개발자도 접근할 수 없습니다.

권한

  • declarativeNetRequest — 규칙에 따라 헤더를 수정하기 위해 필요합니다.
  • storage — 규칙을 사용자 기기에 로컬로 저장하기 위해 필요합니다.
  • 모든 사이트에 대한 호스트 권한 — 사용자가 원하는 모든 사이트에 규칙을 적용할 수 있도록 하기 위해 필요하며, 페이지 내용이나 방문 기록을 읽거나 기록하거나 전송하지 않습니다.

문의

이 정책에 대한 문의는 프로젝트의 GitHub 저장소를 통해 남길 수 있습니다: github.com/Alb3it/modify-header
